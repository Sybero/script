# Sybero Scripts

个人使用的浏览器脚本和 PopClip 扩展集合，按运行环境分目录维护。

## 内容

### Tampermonkey

#### `tampermonkey/touch_video_gestures.user.js`

为支持触摸的设备增强网页视频控制。脚本会自动发现页面中的 `<video>` 元素，并在支持的网站播放器上安装手势监听。

- 单指横向滑动：预览进度变化，松手后跳转；左滑后退、右滑前进。进度使用线性映射，整段视频宽度最多对应 240 秒。
- 双指横向滑动：预览倍速变化，松手后保存，范围为 `0.25x` 到 `4x`。
- 距离较近的双指按住：临时切换到 `4x`，结束或取消时恢复原倍速。
- 单指长按：默认显示当前时间和总时长；开启单指长按快进后，约 500ms 切换到临时 `4x`。
- 提示浮层支持顶部、中部、底部。播放器右上角的齿轮和脚本管理器菜单均可打开页面内设置。
- 支持标准 DOM 全屏；移动设备在浏览器允许时尝试锁定横屏，锁定成功后显示解锁按钮。
- 自动发现动态视频，移除视频时清理监听器；每五秒检查播放器容器变化。

当前内置适配的站点包括：哔哩哔哩（桌面端和移动端）、微博、YouTube（桌面端和移动端）、优酷、Facebook 和腾讯视频。其他使用标准 `<video>` 元素的网站使用父容器作为监听区域。B 站的 `bwp-video` 必须暴露视频媒体 API 才会启用。

脚本使用 `GM_getValue` 和 `GM_setValue` 保存全局及按站点设置，兼容已有设置中的功能开关。设置保存后立即生效。恢复默认会重置全部站点配置。本站禁用后仍可通过脚本管理器菜单重新开启。

运行模式支持“自动、始终启用、始终禁用”。自动模式会根据触摸点数量和粗指针媒体查询判断设备能力；普通鼠标桌面不会创建视频实例、齿轮按钮、MutationObserver 或后台扫描。自动模式下首次收到触摸或触控笔输入后才启动脚本。触摸笔记本可以选择“始终启用”，普通桌面可以选择“始终禁用”。

纵向滑动不调节亮度或音量，默认允许页面滚动。开启“页面内视频纵滑时阻止页面滚动”后，页面内视频区域的纵滑会被拦截。为了识别横向手势，启用手势的监听区域使用 `touch-action: pan-y`，会限制该区域的双指缩放；播放器按钮、输入框和进度滑块不会被脚本接管。

脚本匹配 HTTP 和 HTTPS 页面。iOS 原生视频全屏、封闭 Shadow DOM 内的视频，以及站点自己的触摸手势仍需在目标浏览器实测；原生全屏中不保证能显示网页浮层。脚本不会绕过浏览器对屏幕方向锁定的限制。

#### `tampermonkey/discuz_preview.js`

为 Discuz! 论坛的帖子列表增加“预览”按钮：

- 在帖子列表中直接展开帖子内容，无需离开列表页。
- 通过 iframe 加载帖子，并尽量隐藏帖子页头部和用户信息栏。
- 记录已预览的帖子，按钮会显示为划线状态。
- 监听列表 DOM 变化，兼容分页或异步加载的新帖子。
- 仅在检测到 Discuz! 特征时运行，避免影响普通网页。

预览记录保存在当前站点的 `localStorage` 中，键名为 `discuz_previewed_posts`。跨域或设置了限制响应头的帖子可能无法被 iframe 读取和清理内部元素，但预览页面本身仍可能正常显示。

### PopClip

#### `popclip/popclip_openai.js`

一个 PopClip JavaScript 扩展，用于中英文互译。选中文本后执行 `AI Translate zh/en`，扩展会调用兼容 OpenAI Chat Completions API 的服务，并将翻译结果粘贴回原位置。

- 需要在 PopClip 扩展选项中填写 API Key。
- 当前 API 地址为 `https://ai.chatbro.cn/v1`，模型为 `gpt-4o`。
- 扩展声明了网络访问权限；选中的文本会发送到上述服务，请根据隐私和服务条款要求使用。

## 安装

### 安装 Tampermonkey 脚本

1. 安装 [Tampermonkey](https://www.tampermonkey.net/) 或兼容的用户脚本管理器。
2. 打开对应的 `.user.js` 文件，复制全部内容，或在 Tampermonkey 中新建脚本后粘贴。
3. 保存并启用脚本。
4. 打开匹配的网站；视频脚本需要在触摸设备或浏览器触摸模拟环境中使用。

### 安装 PopClip 扩展

1. 安装 PopClip。
2. 在 PopClip 扩展设置中创建或导入 JavaScript 扩展。
3. 将 `popclip/popclip_openai.js` 的内容作为扩展源码，并填写 `apikey` 选项。
4. 选中文本后打开 PopClip，选择 `AI Translate zh/en` 测试翻译。

## 开发与维护

仓库不包含构建步骤和第三方依赖，脚本均以源码形式直接运行。修改用户脚本时请保留顶部的 Tampermonkey 元数据块；修改 PopClip 扩展时请同步检查扩展头部的名称、权限和选项声明。

视频手势回归测试不依赖第三方包，运行：

```bash
node --check tampermonkey/touch_video_gestures.user.js
node --test tests/touch_video_gestures.test.cjs
```

自动化测试覆盖触摸事件和媒体状态逻辑，不能替代真机验证。提交前建议至少完成以下检查：

- 在目标浏览器中重新加载脚本并确认脚本管理器无语法错误。
- 在一个支持触摸模拟的视频页面验证进度、倍速和全屏操作。
- 在 Discuz! 帖子列表验证展开、关闭、已预览状态及异步加载。
- 在 PopClip 中验证 API Key 配置、网络请求和翻译结果回填。
